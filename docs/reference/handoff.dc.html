01 — 设计支柱

四条不可妥协的支柱

季节即压力
时间不是背景板。草场承载力随季节在 0.6×–1.8× 之间摆动，超载持续掉膘。玩家每年必须做出四次真实的迁徙决策。
城市是长出来的
毡房 → 定居点 → 绿洲城镇是一条不可跳过的路径。每一级都对应真实的生产关系变化：游牧、半定居、坎儿井灌溉农业。
多人是生计
合作牧场共享草料与羊圈；巴扎是玩家挂单撮合；暴风雪与狼群是全服进度条。社交不是聊天室，是共同的生产。
考据不做装饰
羊角纹、巴旦木纹、卡拉库尔羔皮帽、坎儿井竖井间距——每个视觉元素都有出处，不允许生成式的「异域风情」拼贴。
02 — 玩法循环

一年四转场的主循环

春 · 接羔与上山3–5 月 · 诺鲁孜节
母畜集中产羔（羊群 +12%），存栏暴涨但膘情最低。玩家在冬窝子完成接羔后启程上山，沿固定牧道向那拉提转场。这一段是全年唯一的「队伍行进」玩法：牧群跟随、掉队、渡河。
夏 · 那拉提盛草6–8 月 · 那达慕
承载力 1.8×，产量峰值。核心操作是挤奶、剪毛、加工（奶疙瘩 / 酸奶 / 花毡）。那达慕在此期间开放赛马、叼羊、摔跤，是全服玩家唯一的高密度聚集时段。也是建造窗口：木料与银两最充裕。
秋 · 打草贮膘9–10 月 · 秋季巴扎
全年唯一的储备窗口。打草量决定越冬存活率。丝路商队价格峰值，玩家决定卖多少、留多少。出栏（宰杀 / 出售）是一次痛感明确的取舍。
冬 · 冬窝子11–2 月 · 全服事件高发
承载力 0.6×，持续掉膘。暴风雪与狼群是全服协作事件。合作牧场在此刻价值最大：共享草料仓、轮值守夜。年末结算传承——继承者获得父辈的声望与部分牧群。
03 — 世界

五处真实地标

每处地标是一张独立的地图（约 1.2 km × 1.2 km 可行走范围），共享同一套地形着色器与植被系统，靠环境参数区分。转场在地标之间发生，是显式的加载点。

地标 承载 季节 环境特征与专属内容

05 — 网络

权威服务器与同步策略

模拟层 · 20 Hz
经济、膘情、事件进度、市集撮合。服务器唯一真相源，每 tick 推进。玩家指令走可靠通道，服务器校验后应用。
表现层 · 10 Hz 快照
玩家 / 坐骑变换。客户端本地预测 + 100 ms 插值缓冲。牧群个体不同步，只同步 anchor 与 count，个体位置由共享随机种子在各客户端本地演算。
兴趣管理 AOI
每地标一个房间，房间内按 120 m 网格分区。玩家只订阅相邻 9 格。单地标目标承载 60 人在线，超出走分线。

A · 草场承载与掉膘（每游戏日结算一次）
// 羊单位换算：羊 1，牛 3，马 4，骆驼 5
function dailyHerdTick(settlement, region, clock) {
  const units   = sum(herds, h => h.count * SHEEP_UNIT[h.species]);
  const limit   = region.baseCapacityUnits * region.carryingCapacity
                * (1 + shelterbeltBonus(settlement));   // 防风林 +8%/座，上限 +24%
  const load    = units / limit;

  for (const h of herds) {
    let delta = 0;
    if (load > 1)  delta -= (load - 1) * 14;              // 超载惩罚，非线性
    else            delta += (1 - load) * 6;
    if (clock.season === 'winter') delta -= 2.5;
    if (clock.weather === 'blizzard') delta -= 6;
    delta += consumeForage(settlement, h);              // 补饲，最多 +12
    h.condition = clamp(h.condition + delta, 0, 100);

    // 膘情跌破 25 开始死亡；这是玩家必须避免的失败状态
    if (h.condition < 25) {
      const lossRatio = (25 - h.condition) / 100;    // 最坏 25%/日
      const dead = Math.floor(h.count * lossRatio);
      h.count -= dead;
      if (dead > 0) notify(owner, `冻饿损失 ${dead} 头`);
    }
    // 产出与膘情挂钩，低膘不产奶
    const yieldMul = smoothstep(30, 80, h.condition);
    settlement.stock.milk += h.count * MILK_PER_HEAD[h.species] * yieldMul;
    if (clock.season === 'spring' || clock.season === 'summer')
      settlement.stock.wool += h.count * WOOL_PER_HEAD[h.species] * yieldMul;
  }
  settlement.stock.forage -= units * FORAGE_PER_UNIT[clock.season];
}
B · 转场迁徙（显式的多日行程，不是瞬移）
function beginMigration(player, to: RegionId) {
  const days   = REGIONS[player.regionId].travelDays[to];
  const units  = herdUnits(player);
  const forage = units * FORAGE_PER_UNIT.travel * days;

  if (settlement.stock.forage < forage) return reject('草料不足以支撑行程');
  if (activeEvent('blizzard'))       return reject('暴风雪封路');

  settlement.stock.forage -= forage;
  player.migration = { to, startDay: clock.day, days, progress: 0 };
  // 行进期间玩家进入「牧道」场景：牧群跟随、渡河、夜间扎营
  // 每日结算一次风险事件
}

function migrationDayTick(player) {
  const m = player.migration;
  m.progress++;
  for (const h of herds) h.condition -= 3;              // 赶路必然掉膘

  const risk = 0.12 + (herdUnits(player) / 400);        // 群越大越难管
  if (rng() < risk) rollTravelIncident(player);       // 掉队 / 渡河损失 / 遇狼

  if (m.progress >= m.days) {
    player.regionId = m.to; player.migration = null;
    loadRegion(m.to);                                 // 客户端换场景
    grantPrestige(player, 5);                        // 完成转场给声望
  }
}
C · 牧群个体 AI（纯客户端，确定性种子）
// 服务器只知道 herd.anchor 与 herd.count。个体位置在每个客户端上
// 用 hash(herdId, index) 作种子本地演算——所有人看到的画面一致，
// 但一头羊的位置不占带宽。原型已验证 90 只羊 = 2 个 draw call。

function updateAnimal(a, herd, dt, threats) {
  a.restTimer -= dt;
  if (a.restTimer <= 0) {                       // 重新决策：吃草 or 走动
    a.restTimer = 2 + rand(a.seed) * 5;
    a.grazing   = rand(a.seed) > 0.42;
    a.target    = herd.anchor + randInDisc(a.seed, herd.radius);
  }
  // 三条弱规则就够：回中、避让、逃离
  let steer = (a.target - a.pos).normalized() * COHESION;
  for (const n of neighborsWithin(a, 1.2)) steer -= (n.pos - a.pos) * SEPARATION;
  for (const t of threats)                       // 狼、疾驰的马、玩家
    if (dist(a.pos, t.pos) < t.fearRadius)
      steer += (a.pos - t.pos).normalized() * FLEE, a.grazing = false;

  const speed = a.grazing ? 0 : a.baseSpeed;
  a.pos  += steer.normalized() * speed * dt;
  a.pos.y = terrainHeight(a.pos.x, a.pos.z);
  a.yaw   = lerpAngle(a.yaw, atan2(steer.x, steer.z), dt * 3.2);
  a.pitch = a.grazing ? 0.16 : 0;                // 低头吃草
  writeInstanceMatrix(herd.mesh, a.index, a);      // 一次 GPU 上传
}
D · 巴扎撮合 + 丝路商队价格波动
// 玩家挂单为主，NPC 商队做流动性兜底，避免开服冷启动无人交易
function matchOrders(book, resource) {
  const bids = book.bids[resource].sortDesc(o => o.unitPrice);
  const asks = book.asks[resource].sortAsc(o => o.unitPrice);
  while (bids.length && asks.length && bids[0].unitPrice >= asks[0].unitPrice) {
    const qty   = min(bids[0].qty, asks[0].qty);
    const price = (bids[0].unitPrice + asks[0].unitPrice) / 2;   // 中间价成交
    transfer(asks[0].sellerId, bids[0].sellerId, resource, qty, price);
    book.lastPrice[resource] = price;                 // 驱动 UI 行情图
    decrementOrClose(bids[0], asks[0], qty);
  }
}

function caravanTick(clock, book) {
  if (clock.day % 3 !== 0) return;
  const demand = SEASONAL_DEMAND[clock.season];          // 秋季羊毛 ×1.18
  for (const r of RESOURCES) {
    const ref = REFERENCE_PRICE[r] * demand[r];
    // 商队按参考价挂大额单，把玩家价格拉回锚点
    book.addNpcOrder('bid', r, qty: 200, price: ref * 0.92);
    book.addNpcOrder('ask', r, qty: 200, price: ref * 1.08);
  }
  broadcast('丝路商队抵达巴扎');
}
E · 全服协作事件（狼群 / 暴风雪）
function spawnWolfRaid(region, clock) {
  const onlinePlayers = region.players.length;
  const target = 100;
  const wolves = clamp(4 + onlinePlayers * 1.5, 6, 40);   // 按在线人数缩放
  const ev = createEvent({ kind: 'wolf_raid', region,
                           endTick: clock.tick + MIN_10, progress: 0 });
  spawnWolves(wolves, near: weakestFold(region));      // 优先咬没有羊圈的玩家

  // 贡献来源：驱赶（近战 E）、骑马拦截、点燃篝火、羊圈自动防御
  onContribute((playerId, amount) => {
    ev.progress += amount * 100 / target;
    ev.contributions[playerId] = (ev.contributions[playerId] ?? 0) + amount;
    if (ev.progress >= 100) resolveSuccess(ev);
  });

  onExpire(() => {                                     // 失败有真实代价
    for (const p of region.players) {
      const shielded = hasBuilding(p, 'fold') ? 0.4 : 1;
      killHeads(p.herds.sheep, ratio: 0.06 * shielded);
      p.herds.forEach(h => h.condition -= 8 * shielded);
    }
  });

  // 奖励按贡献占比分配，保底参与奖，防止只有大佬吃肉
  function resolveSuccess(ev) {
    const total = sum(values(ev.contributions));
    for (const [pid, c] of entries(ev.contributions))
      grant(pid, silver: 60 + 400 * (c / total), prestige: 2);
  }
}
F · 代际传承（年末结算）
function yearEnd(player) {
  const score = player.prestige
              + settlement.population * 2
              + herdUnits(player) * 0.5
              + buildingsOfTier(player, 3).length * 20;

  if (player.generation >= GENERATION_SPAN) {          // 默认 12 年一代
    // 传承不是重开：建筑、聚落、声望全留，牧群按膘情折损，
    // 玩家换一个新角色（外观继承父辈纹样），获得一条家族特质。
    player.generation++;
    player.appearance = inheritAppearance(player.appearance);
    player.traits.push(rollTrait(score));             // 如「识途」转场耗时 -20%
    herds.forEach(h => h.count = floor(h.count * 0.85));
    unlockChronicleEntry(player, year, score);        // 家族史，可在毡房内翻阅
  }
}
07 — 渲染

卡通渲染管线（原型已验证）

原型中这套管线在 1920×1080 稳定 60 fps，场景含 13000 株草、90 只羊、24 头牛、5 个角色、全部带描边。以下参数可直接搬走。

赛璐璐分层
四阶 ramp [0.46, 0.68, 0.86, 1.0] 用于角色与近景，三阶柔和 ramp [0.66, 0.84, 1.0] 用于远山与云——远景用硬阶会在地平线压出一道死黑带，这是踩过的坑。
法线外扩描边
背面剔除反转 + 顶点沿法线外推固定世界单位（角色 0.010–0.018，动物 0.022–0.028，建筑 0.030）。不用后处理边缘检测：实例化对象可共用一套 shader，且描边粗细不随距离抖动。
合批策略
每种动物 / 建筑把所有部件合并成一个带顶点色的 BufferGeometry，再用 InstancedMesh 铺开；描边网格直接复用同一个 instanceMatrix。一个 90 只的羊群 = 2 次 draw call。
草与风
十字双面片 + 顶点渐窄，实例矩阵的平移分量做相位种子，在 begin_vertex 里按高度加权摆动。实例色只做明度扰动，色相全由材质 color 控制——换季一行代码把整片草原染白。
EnvProfile — 季节 × 地标的环境参数表
interface EnvProfile {

10 — 交接边界
原型里已经能跑的
卡通渲染 + 描边 · 地形与河流 · 风吹草动 · 天山远景 · 昼夜与四季 · 第三人称控制与骑乘 · 羊牛马群 AI · 挤奶剪毛互动 · 建造放置与幽灵预览 · 八套界面 · 转场换环境 · 全服事件进度 · 竞技小游戏 · 换装实时重建 · 触屏摇杆
原型里是假的、需要你实现的
所有「其他玩家」都是本地 NPC · 市集挂单是静态数据 · 全服进度条是定时器 · 没有服务器、没有存档、没有账号 · 转场是就地换色而非多日行程 · 建筑没有实际产出结算 · 没有音频 · 角色是程序化几何体，需要美术替换为正式模型（保留同一套骨骼与外观枚举）
给实现方的一句话：先把 §06-A（承载与掉膘）跑通并调平，其余系统都是它的外围。这个游戏好不好玩，取决于玩家在「多养一百只羊」和「今年能不能安全过冬」之间是否真的会犹豫。
